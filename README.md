# Overview

It has been a long term goal of mine to design and program a board game style project like this. This project is really just a first attempt and I hope to improve my knowledge and develop more complex interactive games like this in the future. 

I used a variety of functions to accomplish my goal of a working checkers style game. In particular, I used recursion to prevent a player's turn from ending when they make an illegal move. I also used a variety of both for and while loops to keep the game running until a winning condition is met by one of the players.
